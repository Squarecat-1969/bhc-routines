- **THE ONE UNVERIFIED SURFACE — Attio email metadata.** The spec's central scoring insight (inbound vs outbound computable from Attio's own email metadata, no Gmail) depends on an endpoint this repo has never called: Attio's email data is reachable via the MCP connector, but GitHub Actions has no MCP host — the same constraint that put every other Attio call here on REST — and the REST path and field names in `src/lib/attio-emails.ts` are an informed guess, not a checked fact. Structural properties are asserted rather than assumed: two-way correspondence outweighs any single other signal; every count bonus is gated behind span, so "12 emails in one hour" can never score as a relationship; client-team coherence is positive and blast is negative, with recipient count contributing nothing to the score on its own (it decides only the provenance line).

Skipped rows return to pending when `skip_until` passes or immediately on new interaction evidence.
